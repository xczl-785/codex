# Mission: 掌握 Codex 源码架构

## Why

通过系统阅读这个可运行的 Codex fork，形成能够独立定位、解释和修改核心 Agent 行为的源码能力，而不是只记住零散函数名。最终能把 Thread、Turn、工具调用和 Subagent 等概念对应到真实代码与运行链路。

## Success looks like

- 能用自己的话讲清一次用户输入从界面到核心运行时、再到结果返回的过程。
- 面对一个功能问题时，能先判断它属于界面、协议、Thread、Turn、工具、模型还是存储层。
- 能借助 CodeGraph 找到关键入口、调用关系和对应测试，而不是盲目全文搜索。
- 能持续产出简洁、准确、可以复习的源码学习文档。

## Constraints

- 以静态阅读为主，本机不要求编译或运行整个仓库。
- 解释优先使用通俗语言和类比，再逐步引入真实类型与函数名。
- 已了解常见编程和 Agent 概念，但尚不熟悉本仓库的大量 crate、模块与符号。
- 学习分支仍需保留构建、运行和基础验证所需的工程结构。

## Out of scope

- 一开始就记忆全部 crate、函数名或协议字段。
- 上游贡献、发布、宣传和仓库治理流程。
- 在尚未形成整体地图前深入平台构建与边缘实验模块。
