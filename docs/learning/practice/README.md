# 实践与工程改进参考

本目录集中提供独立实验工程的实践契约、验收材料，以及暂存的工程改进调研。它们服务于实际工程工作，不属于课程阅读顺序。

## 按用途查阅

| 用途 | 材料 | 使用边界 |
| --- | --- | --- |
| 确定实践目标、范围与进入条件 | 下列编号实践 | 保存契约，不代表当前已启动或已完成 |
| 实现或核对具体行为场景 | [验收材料](materials/README.md) | 配合所属实践使用，不作为独立任务 |
| 登记后续改进、讨论候选方案 | 下列工程改进调研 | 提供背景和建议，不自动形成实施授权或既定契约 |

教学衔接与推荐实践顺序见 [MAINTENANCE.md](../MAINTENANCE.md)。目标工程的实时实现、deferred 登记、启动时机和验收状态，由该工程自己的 `docs/STATUS.md` 维护；本目录不镜像这些状态。

## 编号实践

- [0001：实现一个通用代码库理解 Agent](0001-codebase-study-agent.md)：绑定任意本地代码库，通过只读工具和证据约束实现 Agent Harness，以 Codex 作为对照样本。
- [0002：权限、审批、沙箱与提权](0002-permission-sandbox-lab.md)：用确定性替身贯通动作准入、受限执行和失败分类。
- [0003：持久恢复与同 Turn 上下文压缩](0003-context-history-recovery-lab.md)：区分持久事实与恢复、容量准入与自动压缩。
- [0004：取消传播与部分完成状态](0004-cancellation-propagation-lab.md)：固定取消竞态、部分完成、历史收口与重启恢复的契约。
- [0005：有界并行工具调度与结果顺序](0005-bounded-parallel-tool-scheduling-lab.md)：研究共享/独占准入、并发上限与稳定历史顺序。
- [0006：Subagent 委派、通信与生命周期](0006-subagent-lifecycle-lab.md)：先处理 M0.5 单 Agent Queue/Steer 前置机制，再进入 Subagent 实践。

编号用于标识材料；当前推进顺序与状态应沿上面的所有权入口确认，不从编号或文件是否存在推断。

## 工程改进调研

- [CodebaseAgent TUI 间距与视觉边界](tui-spacing-investigation.md)：记录字符网格限制、框架与社区实践对照，以及保留 Ratatui 的轻量改进建议；第 9 节提供 deferred 登记摘要。
