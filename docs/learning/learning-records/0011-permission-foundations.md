## 讲解中需要保留的纠正

- Allow 不能一概推断为必定使用默认沙箱；要结合规则来源和有效配置。
- SandboxDenied 只描述沙箱拒绝，不等于审批拒绝，也不能单凭名字确定是否已经返回主模型。
- 内部重试可以复用 Tool Call，模型重新调用则产生新的 Tool Call；当前暂缓细化这些分支。
- 沙箱不会识别全部危险业务行为，也不会回滚此前成功写入。
- Linux 权限码只是理解资源访问的类比，Profile 不等于修改文件本身权限。
