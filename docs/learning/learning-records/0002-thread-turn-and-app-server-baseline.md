# 学习记录 0002：Thread、Turn 与 App Server 理解基线

## 已经掌握

- 能把 Thread 识别为“对话/长期工作会话”的领域抽象，而不是操作系统线程。
- 能把 Turn 识别为 Thread 内的一轮执行，并主动注意到连续发送可能改变当前 Agent 的回复方向。
- 已开始区分界面表现与运行时真实边界，不再只按聊天气泡数量判断 Turn。

## 本轮校准

- Turn 更准确地说是一段连续的 Agent 执行生命周期，不严格等于“一条用户消息加一条助手回复”。
- 活动 Turn 仍可接收输入时，TUI 会优先尝试 Steer；空闲时才启动新 Turn。
- App Server 是对客户端暴露 Thread/Turn 能力的接口与协调边界，不是位于 Thread、Turn 之上的领域概念层。

## 后续教学假设

可以从概念辨析转入状态与事件流，但仍应先用场景说明，再引入源码中的类型和函数名。
