# 学习记录 0003：从生命周期定义转向设计动机

## 已经掌握

- 能正确判断恢复旧对话并提交新请求时，旧 Thread 被沿用，而 Session、Turn 和 Task 重新产生。
- 已经理解 Thread、Session、Turn、Task 的基本职责和生命周期差异。

## 当前学习障碍

只讲概念定义、包含关系和源码位置会产生“听得懂但不知道为何存在”的感觉。真正需要补足的是架构拆分背后的问题、约束与反事实。

## 后续教学调整

介绍架构概念时，固定回答：

1. 它是什么；
2. 为什么要与相邻概念分开；
3. 这种设计解决了什么问题；
4. 不这样设计会出现什么故障或维护成本。

先用场景和反事实建立设计动机，再进入类型、字段和调用路径。
