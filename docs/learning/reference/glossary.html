Codex 核心概念速查

先记职责，不急着记实现。遇到源码名词时回到这里校准。

Thread

一段可以持续、恢复和派生的工作会话，像一个长期保存的工作台。

Turn

Thread 中的一轮工作，从一次输入开始，到这一轮完成、中断或失败。

Session

Thread 在内存中的运行实体，持有服务、状态和处理操作的能力。

Task

一次 Turn 内实际执行的工作形态，例如普通处理、压缩或代码评审。

Op

送进核心 Thread 的操作消息，例如启动输入、中断、审批结果或配置变化。

Event

核心向外报告的事件消息，例如内容增量、工具调用、Turn 完成或错误。

App Server

稳定的应用接口层，把 TUI、IDE 和 SDK 请求翻译成核心 Thread 操作。

ThreadManager

管理多个 Thread 的总管，负责创建、恢复、派生、查找和关闭。

CodexThread

调用方握在手里的 Thread 句柄，提供投递操作和订阅事件的通道。

Tool

模型可以请求使用的外部能力，相当于 Agent 的手，例如执行命令或修改文件。

Context

一次模型请求能看到的信息集合，包括历史、指令、环境和工具结果。

Subagent

由另一个 Agent 创建的子工作者，本质上复用独立 Thread 和正常 Turn 机制。
